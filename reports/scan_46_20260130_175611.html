SSTI (Velocity)

1 Finding(s)

SSTI occurs when user input is embedded directly into a template engine's template, allowing attackers to inject template directives and execute arbitrary code on the server.

1. Application uses template engine (Jinja2, Twig, FreeMarker, etc.) 2. User input is directly embedded in template string 3. Attacker injects template syntax (e.g., {{7*7}}) 4. Template engine evaluates the expression, potentially executing code

  • Remote code execution on server
  • Complete server compromise
  • Data theft
  • Lateral movement in network

Remediation Steps

  • Never pass user input directly to template.render()
  • Pass user data as context variables, not template content
  • Use sandboxed template environments
  • Implement strict input validation
  • Use logic-less template engines when possible
